# Análise de Vendas: PostgreSQL + Power BI

Projeto prático desenvolvido durante o curso de PostgreSQL (instrutora Midori Toyota) para consolidar conhecimentos em SQL e integração de dados com ferramentas de BI.

## 📌 Objetivos
* Estruturar um banco de dados relacional para análise de vendas.
* Validar KPIs de negócio via queries SQL.
* Integrar e tratar os dados no Power BI para visualização.

## 🛠️ Tecnologias Utilizadas
* **PostgreSQL:** Armazenamento e manipulação dos dados.
* **SQL:** Criação de tabelas, JOINS e agregações.
* **Power BI / Power Query:** Limpeza de dados (ETL), ajuste de tipagens e conversão de moeda (ponto para vírgula).

## 📊 O Projeto
O fluxo de trabalho consistiu em extrair as informações do banco de dados e garantir que os dados chegassem limpos ao Power BI. Um dos pontos chave foi o tratamento no Power Query para converter formatos numéricos americanos para o padrão de moeda nacional.
